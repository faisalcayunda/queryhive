# QueryHive 0.2.1

A small release. Nothing about what the app does changed: 0.2.1 is the same code as 0.2.0 with the
three things fixed that kept 0.2.0 from building on a machine other than the one it was written on.

## In this release

**The app builds from a clean checkout again.** Continuous integration compiles on macOS 15 with
Xcode 16.4 (Swift 6.1), and three things in 0.2.0 only the newer Swift on the author's Mac accepted:

- `AppModel+Export.swift` had a local `let connection` sitting in the same brace block as a call to
  the method `connection(for:)`. Swift scopes a local to its whole block, so 6.1 resolved the call to
  the local `Connection?` instead of the method and reported the older `??` chain above it as a
  "circular reference". The local is now named `targetConnection`.
- `ResultGrid.swift` wrapped a `map`, five concatenated lines and a `??` inside one `Text(...)`, and
  6.1 gave up with "unable to type-check this expression in reasonable time". The string is now a
  `subtitle` property.
- The tests that compare *rendered pixels* against recorded baselines (the chrome and grid
  appearance gates) now run where that comparison means something. They pin the font rasteriser, the
  SDK, the GPU and the system's accessibility switches, all of which a headless CI runner provides
  differently, and 0.2.0's CI never reached them to notice. They still run on a developer's machine
  and can be forced anywhere with `QH_RENDER=1`.

Nothing here is visible in the app. If you are on 0.2.0 there is little reason to take it beyond
staying current; if you build QueryHive from source, this is the release that builds.

## Installing

`QueryHive-0.2.1-arm64.dmg` is signed but not notarized, exactly as 0.2.0 was. On first launch,
**right-click the app and choose Open**, or use System Settings → Privacy & Security → Open Anyway.
After that it behaves normally, and updates install themselves.

- `QueryHive-0.2.1-arm64.dmg` — the app
- `appcast.xml` — the update feed the app reads; it has to stay attached to this release
